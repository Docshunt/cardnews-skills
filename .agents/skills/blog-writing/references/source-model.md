# Source model: original insight, Korean intent, practical action

Use two source layers when a Docshunt post starts from an overseas article.

| Layer | Use it for | Do not use it for |
| --- | --- | --- |
| Overseas original | a contrarian claim, founder case, experiment, product or growth insight, and the story tension | Korean programme eligibility, application deadline, funding amount, or a claim about a specific Korean evaluator |
| Korean official source | programme vocabulary, current public notices, application procedures, eligibility, guides, and legal/financial conditions | a substitute for the article's point of view or a justification for advice it does not state |
| Docshunt translation | connecting the insight to the reader's business-plan evidence or decision | repeating source summaries without a useful action |

## Build the bridge

Use this sequence:

1. **Origin:** State the useful overseas insight in one original Korean sentence.
2. **Tension:** Show the Korean founder's familiar mistake or unresolved question.
3. **Evidence:** Add the relevant official vocabulary or condition only if it changes the decision.
4. **Translation:** Name the exact business-plan field or proof to improve.
5. **Action:** Give the reader a small next action before the CTA.

Example:

```text
Origin: An early product is not validated simply because people try it once.
Tension: Many AI startup plans describe market size but leave repeat use unproven.
Evidence: A current Korean programme may ask for commercialisation or feasibility evidence;
          link the actual notice instead of inferring an unlisted evaluation rule.
Translation: Put repeat-use, inquiry, retention, or pilot evidence in feasibility and execution milestones.
Action: Collect the last ten user responses and label each as first use, repeat use, or refusal.
```

## Keyword discipline

Choose one query family per article. Add programme keywords only when the post genuinely helps the reader make a related decision.

- Good: `AI 창업 사업계획서에서 고객 검증을 쓰는 법`
- Good: `예비창업 지원사업을 준비할 때 고객 인터뷰를 정리하는 법`
- Weak: `사업계획서 AI 지원사업 창업 정부지원금 성공 전략`

Keep current programme articles separate from evergreen explainers. A time-sensitive post must carry its notice date/version and be updated or clearly marked after its relevance expires.
