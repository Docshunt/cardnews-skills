# Korean editorial pass

Use this reference after the article is factually complete. Preserve meaning before improving rhythm.

## Detect

Flag only the phrase or sentence that needs work.

- **Translation-like phrasing:** `~를 통해`, `~에 있어서`, `~에 대해`, `~에 의해 생성된`, unnecessary English in parentheses, abstract subjects that perform actions.
- **Formulaic structure:** consecutive `첫째/둘째/셋째`, repeated `이것은`, same sentence length, same ending three times, section-heading inflation, bullet lists that could be prose.
- **Filler and hedging:** `결론적으로`, `시사하는 바가 크다`, `주목할 만하다`, `중요한 점은`, `~할 수 있을 것으로 보인다`, `~할 필요가 있다`.
- **Over-decoration:** stacked questions, excessive bolding, quotation marks used as decoration, emoji, em dash, and forced contrasts.

## Rewrite

| Instead of | Prefer |
| --- | --- |
| `AI 기술을 통해 효율을 높일 수 있다` | `AI로 처리 시간을 줄일 수 있다` when the source supports it |
| `이에 있어서 중요한 점은` | delete it or state the point directly |
| `~에 의해 생성된 결과` | `~가 만든 결과` when the agent is known |
| `결론적으로, 이는 시사하는 바가 크다` | delete it; state the implication concretely if one exists |
| uniform short sentences | vary length while preserving the reading pace |

## Strict review

Use strict mode for long, sensitive, or user-designated drafts.

1. List protected facts from the source sheet.
2. Make a span-level finding list: phrase, category, severity, proposed minimal edit.
3. Apply only accepted edits.
4. Compare every changed sentence with the source draft and source links.
5. Check that a factual statement did not turn into a stronger claim, a direct quote did not change, and a programme rule was not reinterpreted.
6. Stop and report rather than over-editing when naturalness would require changing the writer's point of view or evidence.
