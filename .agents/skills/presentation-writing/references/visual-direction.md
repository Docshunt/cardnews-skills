# 발표자료 시각 기준

이 기준은 카드뉴스의 절제된 사진·글·여백 원칙을 16:9 발표자료로 옮긴 것이다. 사진은 완성 전까지 중립 회색 도형으로 표시하고, 사용자가 실제 사진을 넣을 때 그 도형을 같은 크기의 사진으로 교체한다.

## 기본 규격

| 항목 | 기준 |
| --- | --- |
| 캔버스 | 1600 × 900, 16:9 |
| 기본 여백 | 좌우 104px, 위 80–96px, 아래 56–72px |
| 제목 | 56–64px, 800–900, 줄간격 1.08–1.15 |
| 일반 슬라이드 제목 | 42–48px, 800–900, 줄간격 1.15–1.22 |
| 본문 | 26–30px, 500–600, 줄간격 1.48–1.60 |
| 인용문 | 42–48px, 가운데 정렬, 줄간격 1.42–1.55 |
| 출처 | 14–16px, 하단 왼쪽, 필요한 슬라이드에만 |
| 바탕 | `#FCFCFA` |
| 글자 | `#111111` |
| 사진 자리표시자 | `#F1F1ED`, `#111111`의 1–1.5px 선 |

모든 제목과 본문은 하나의 한국어 산세리프를 쓴다. 인용문만 한국어 세리프를 사용할 수 있다. 강조는 한 문장 또는 한 구절에만 굵은 검정 밑줄로 한다.

## 다섯 슬라이드 형태

| 형태 | 구도 | 쓰임 |
| --- | --- | --- |
| `opening` | 왼쪽 40%에 제목과 짧은 설명, 오른쪽 60%에 세로로 꽉 찬 사진 자리표시자. | 표지와 첫 주장 |
| `quote` | 왼쪽 42%에 가운데 정렬 인용문, 오른쪽 58% 상단에 가로 사진 자리표시자와 얇은 검정 테두리. | 실제 인용, 목소리, 결정적 발언 |
| `text-image` | 왼쪽 42%에 제목·본문, 오른쪽 58%에 큰 사진 자리표시자. | 설명, 시간순 맥락, 근거 |
| `image-text` | 왼쪽 54%에 세로로 꽉 찬 사진 자리표시자, 오른쪽 46%에 제목·본문. | 사진이 먼저 감정을 만들고 해석이 뒤따를 때 |
| `centered-close` | 사진 없이 중앙 60% 폭에 제목·짧은 설명·결론을 가운데 정렬. | 결론, 제안, 기억할 한 문장 |

좌우 분할은 발표 화면에서 한눈에 읽히게 바꾼 것이며, 인접 슬라이드에서 동일한 실루엣을 세 번 연속 반복하지 않는다. 사진 자리표시자는 실제 사진이 들어갈 정확한 위치와 비율을 정하는 도구일 뿐, 완성 슬라이드에 남겨 두지 않는다.

## 사진 자리표시자 규칙

- 도형 안에 `사진: [구체적 대상] · [가로/세로]`로 쓴다. 예: `사진: 회의 중인 인물 · 세로`.
- 모서리를 둥글게 하지 않고, 그림자·장식 프레임·캡션 배지를 더하지 않는다.
- `text-image`, `image-text`, `opening`의 사진은 도형을 삭제한 뒤 그 영역 끝까지 사진을 채운다.
- `quote`의 사진만 1–1.5px 검정 테두리를 유지한다.
- 사진 안에 제목, 본문, 수치, 한국어 문구를 구워 넣지 않는다. 모든 한글은 별도 텍스트 상자로 유지한다.

## 금지 요소

- 빨강 등 포인트 색, 그러데이션, 아이콘, 스티커, 장식 도형
- 상단 카테고리, 페이지 번호, 복잡한 헤더, 과한 로고
- 한 장에 여러 주장, 작은 본문, 빽빽한 글머리표
- 사진의 둥근 모서리, 장식 프레임, 반복 카드 UI
- 출처 없는 수치와 인용문, 실제 근거 없는 그래프

## 검토 기준

전체 화면과 발표자에게 보이는 크기에서 다음을 모두 확인한다.

- 첫 슬라이드는 첫 문장만으로 발표의 주장을 이해할 수 있는가?
- 각 슬라이드는 하나의 질문에 답하거나 다음 슬라이드의 질문을 만드는가?
- 제목과 첫 문단을 확대하지 않고 읽을 수 있는가?
- 사진 자리표시자가 메시지와 직접 관계 있는 사진을 구체적으로 요구하는가?
- 실제 인용, 수치, 사진에 출처 줄과 발표자 노트의 `[Sources]`가 있는가?
- 강조가 검정 밑줄 한두 곳으로 제한되어 있는가?
- 겹침, 잘림, 두 줄이 된 단일 행 제목, 남은 빈 자리표시자가 없는가?
- 마지막 장이 `감사합니다`가 아니라 결론이나 다음 판단으로 끝나는가?
